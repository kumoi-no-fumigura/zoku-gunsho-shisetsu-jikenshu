## 作品について

冷泉家から相伝した師説と、自分の見解とを合わせて記したと奥書にいう歌学書。源氏物語の詞、鳥・調度などの歌語を項目ごとに取り上げて注する。寛正5年の書写奥書がある。

## 底本

- [続群書類従 巻468（師説自見集）](https://www.digital.archives.go.jp/item/734637)（国立公文書館・塙保己一 編・続群書類従）

国立公文書館の公開画像です（画像の出典: 国立公文書館）。

## 本文の作り方

国立公文書館の公開画像を、国立国会図書館の NDL古典籍OCR-Lite でテキスト化し、原本のページごとに段落に分けました。写本の崩し字の OCR なので、誤りが多く残っています。

## ファイル

| パス | 中身 |
|---|---|
| `honbun/` | 本文。1 行が 1 段落で、`段落ID<TAB>本文` の形です。原本の行の切れ目は ⏎ で示しています（⏎ は改行の印で、本文の字ではありません）。50段落ごとにファイルを分けています（3ファイル）。 |
| `uta.tsv` | 作中歌の一覧（番号・段落ID・本文・読み・詠み手・種別・原本のコマ）。 |
| `zoku-gunsho-shisetsu-jikenshu.json` | 本文・底本・作品の説明・作中歌のデータをまとめた JSON（訳は入れず、`yaku/` だけに置いています）。 |

段落ID（例: `zoku-gunsho-shisetsu-jikenshu-0001`）は、本文を直しても変わりません。

## 誤りを見つけたら


- **Issue で知らせる**：[「本文の誤り」の Issue を作る](https://github.com/kumoi-no-fumigura/zoku-gunsho-shisetsu-jikenshu/issues/new?template=teisei.yml)。段落ID・いまの本文・直した本文・根拠を書いてください。
- **直接直す**：`honbun/` の該当行を直して Pull Request を送ってください。段落IDと行の順番は変えないでください。

受け取った修正は、底本と照らして確かめてから取り込みます。
